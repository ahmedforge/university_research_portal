# University Research Opportunity Portal

Computer Networks Assignment 01 — Fall 2026.

A web application for creating, viewing, updating, closing, and deleting
university research opportunities.

## Project status

Stage 1: repository structure created.
The application is not runnable yet.

## Planned technology stack

- Backend: Python, FastAPI, Uvicorn, and Pydantic
- Database: MySQL, SQLAlchemy 2.x, and PyMySQL
- Frontend: HTML, CSS, vanilla JavaScript, and Bootstrap 5
- API testing: Postman

SQLAlchemy separates database access from API routes and supports
parameterized queries. PyMySQL provides a Python MySQL driver without
requiring a compiled driver dependency.

## Repository structure

- backend/ — REST API source code
- frontend/ — browser interface
- database/ — database schema and setup files
- postman/ — exported API testing collection
